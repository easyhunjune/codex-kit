# 계획 문서

## 만들 때
계획 문서(기본 `docs/PLAN.md`)에 아래 칸을 채운다. 칸마다 3줄 이내로 쓴다.

- 목표: 과제가 요구하는 결과물 한 줄
- 완료 기준: 확인 가능한 조건 (예: 명령 X를 실행하면 Y가 나온다)
- 제약: 과제 안내에 적힌 조건, 시간, 실행 환경
- 가정: 자료에 없어서 임시로 정한 것. 실무자 답을 받으면 근거를 붙여 고친다
- 범위 밖: 이번에 하지 않을 것
- 마일스톤: 30~40분 단위로 나누고 각각 완료 기준 한 줄
- 위험: 실패할 수 있는 지점과 대비책

계획을 사용자에게 보여 주고 확인을 받은 뒤 코드를 쓴다.

## 판단을 기록할 때
설계를 고르거나 바꿀 때마다 계획 문서의 판단 기록 표에 한 줄씩 덧붙인다.
